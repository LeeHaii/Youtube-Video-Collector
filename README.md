# 🎬 Rhymx's YouTube Ultimate Tool

An all-in-one desktop workflow tool for **collecting YouTube timestamps, downloading clips, trimming videos, and automating CapCut projects**.

Originally built as **YouTube Video Collector**, the project has grown into a multi-tool Electron application combining YouTube research/collection utilities with several CapCut automation tools.

> ⚠️ This project is primarily designed for **Windows**. Some tools directly modify CapCut project files or automate desktop applications, so back up important projects before processing them.

---

## ✨ Features

### 📍 YouTube Video Collector

Watch YouTube inside the application and quickly collect important timestamps.

* Embedded YouTube browser
* Press **`,` (comma)** to create a marker
* Visual markers on the YouTube timeline
* Click markers to seek back to marked positions
* Undo/remove markers
* Collect multiple videos into one row
* Organize multiple rows
* Edit previously collected rows
* Delete individual URL/timestamp pairs
* Display timestamp counts per row
* Export everything to CSV
* Load existing CSV files
* Automatic `.rhymx` session backups
* Configurable autosave interval
* Optional **5-second offset marking**

---

### ⬇️ 5-Sec Downloader

Turn collected timestamps into actual video clips.

* Reads CSV files generated by the collector
* Downloads a 5-second section from every timestamp
* Supports multiple videos and timestamps per row
* Downloads targeted ranges instead of intentionally downloading the complete source first
* Up to 1080p when an appropriate format is available
* FFmpeg processing
* Configurable delays between clips
* Configurable delays between rows
* Start / Stop controls
* Live download log
* Open output directory directly
* Extract failed/rate-limited items to a retry CSV
* Error tracking for restricted videos

---

### ✂️ YouTube Trimmer

Download an arbitrary section of a YouTube video.

* Embedded video preview
* Paste a YouTube URL
* Select exact start and end timestamps
* `HH:MM:SS.mmm` controls
* Millisecond input
* Preview automatically seeks when changing the start timestamp
* Uses the active YouTube session cookies when available
* Targeted section downloading with `yt-dlp`
* Multiple format fallbacks
* FFmpeg integration
* Node.js support for newer YouTube JavaScript challenges
* Live processing log

---

### 🎲 CapCut Shuffle

Randomize clips inside CapCut projects.

* Scan a CapCut project directory
* Search projects by name
* Select multiple projects
* Shuffle clips using timeline marker ranges
* Process `draft_content.json`
* Optional cache refresh
* Batch processing
* Live status output

> **Back up your CapCut projects first.** This tool directly changes CapCut project data.

---

### ✨ Auto Add Effect & Title

Batch-process CapCut projects with automated effects and titles.

* Scan CapCut projects
* Search and multi-select projects
* Auto Add Effect
* Auto Add Title
* Extract title lines from pasted text
* Log marker timestamps
* Optional **Skip Intro**
* Process multiple projects in one operation
* Live processing log

The title extractor currently recognizes lines containing combinations of tokens such as:

```text
Number
:
번호
Número
Numéro
番号
```

---

### 🎥 CapCut Auto Render

> ⚠️ **Deprecated / experimental**

The application still contains the older CapCut Auto Render interface for automating the CapCut export workflow.

It includes:

* Project scanning
* Multi-project selection
* Configurable automation delays
* CapCut export automation
* Processing logs

This tab is explicitly marked **Deprecated** in the current UI and should not be considered part of the recommended workflow.

# 🚀 Running From Source

## Requirements

For the Electron application:

* Node.js
* npm
* Windows recommended

For building the bundled helper tools:

* Python 3.8+
* PyInstaller
* `yt-dlp`

cd Youtube-Video-Collector/youtube-video-collecting

npm start

# 📍 YouTube Collector Usage

## 1. Open a YouTube Video

Use the embedded YouTube browser to navigate to the video you want to collect.

The browser includes:

```text
← Back
→ Forward
⟳ Refresh
```

---

## 2. Add Markers

While the YouTube video is focused, press:

```text
,
```

The comma key captures the current video position.

Example:

```text
Video playing at 02:41
         │
         ▼
     Press ,
         │
         ▼
     Marker: 2.41
```

Markers are also displayed on the YouTube timeline.

---

## 3. Optional 5-Second Offset

Open:

```text
⚙ Setting
```

and enable:

```text
Offset Marking Method
```

With this enabled, the timestamp is recorded **5 seconds before** the moment you press the marker key.

Example:

```text
Press marker at:  8:40
Recorded marker:  8:35
```

This is useful when you notice an interesting moment and react a few seconds after it starts.

---

## 4. Save the Current Video

After adding markers, click:

```text
Take URL + Markers
```

The current row receives:

```text
YouTube URL
+
semicolon-separated timestamps
```

For example:

```text
https://www.youtube.com/watch?v=VIDEO_ID
0.15;1.20;2.45
```

You can then open another video and add it to the same row.

---

## 5. Create Another Row

Click:

```text
Next Row
```

to finish the current group and begin another.

Example:

```text
Row 1
├── Video A → 0.15;0.30
└── Video B → 1.20;2.10

Row 2
└── Video C → 0.05;3.15
```

---

# ⏱️ Timestamp Format

Collector timestamps are stored as:

```text
MM.SS
```

or, for videos longer than one hour:

```text
HH.MM.SS
```

Examples:

| Timestamp | Meaning  |
| --------- | -------- |
| `0.05`    | 00:05    |
| `0.30`    | 00:30    |
| `1.20`    | 01:20    |
| `10.45`   | 10:45    |
| `1.05.20` | 01:05:20 |

Multiple timestamps are separated using:

```text
;
```

Example:

```text
0.15;1.20;2.45
```

---

# 📄 CSV Format

Each row alternates between:

```text
URL,TIMESTAMPS,URL,TIMESTAMPS,...
```

Example:

```csv
https://www.youtube.com/watch?v=AAA,0.15;0.30,https://www.youtube.com/watch?v=BBB,1.20;2.10
https://www.youtube.com/watch?v=CCC,0.05;3.15
```

Conceptually:

```text
Row 1
├── URL A
│   ├── 00:15
│   └── 00:30
│
└── URL B
    ├── 01:20
    └── 02:10

Row 2
└── URL C
    ├── 00:05
    └── 03:15
```

This format is also consumed by the integrated **5-Sec Downloader**.

# 💾 Autosave & Recovery

Collected data can automatically be saved into `.rhymx` files.

Autosaves contain:

```text
rows
currentRow
timestamp
version
```

The autosave interval can be configured from:

```text
Settings
```

between:

```text
1 – 60 minutes
```

The application stores autosaves inside the operating system's temporary directory under:

```text
youtube-collector-autosaves/
```

You can use:

```text
📂 Load
```

to load either:

```text
.rhymx
```

or:

```text
.csv
```

files.

# ✏️ Editing Collected Data

The current version supports more than simply collecting and exporting.

Inside the collected rows table you can:

* Click a row number to edit that row
* Click a URL to load its video and timestamps
* Change markers
* Save the modified row
* Append more URLs to an existing row

This allows a collection session to be reviewed before exporting.

# ⬇️ 5-Sec Downloader Usage

First export your collector data to CSV.

Then open:

```text
5-Sec Downloader
```

Choose:

```text
Input CSV
Output Folder
```

Configure optional delays:

```text
Between Clips: 1 – 2 seconds
Between Rows:  10 – 15 seconds
```

and click:

```text
Start
```

---

## Download Behavior

Every timestamp produces a 5-second clip.

Example:

```text
Timestamp: 1.20

Downloaded range:

01:20 ───────────── 01:25
       5 seconds
```

The downloader uses `yt-dlp` range downloading and FFmpeg processing.

---

## Output Structure

Each non-empty CSV row gets its own directory.

For example:

```text
output/
├── 1/
│   ├── 1.1.1.mp4
│   ├── 1.1.2.mp4
│   └── 1.2.1.mp4
│
└── 2/
    ├── 2.1.1.mp4
    └── 2.1.2.mp4
```

The naming scheme represents approximately:

```text
ROW.URL.CLIP
```

---

## Rate Limiting

The downloader includes configurable random pauses to reduce continuous request bursts.

If downloads fail, the UI can expose buttons for exporting problem items into separate CSV files, including rate-limit/retry data.

Those files can then be processed again later.

Open:

```text
YouTube Trimmer
```

### 1. Select an output folder

### 2. Paste the YouTube URL

### 3. Click `OK`

The video will load in the integrated preview.

### 4. Enter a start time

```text
HH : MM : SS . MS
```

### 5. Enter an end time

```text
HH : MM : SS . MS
```

Example:

```text
Start: 00:01:25.500
End:   00:01:42.000
```

### 6. Click

```text
Download Trimmed Video
```

The trimmer requests the selected video range and saves the result to the chosen output directory.

When possible, cookies from the embedded YouTube session are passed to the downloader. This can help with videos requiring an authenticated session.

# 🎥 CapCut Auto Render

The UI currently labels this feature:

```text
CapCut Auto Render (Deprecated)
```

It was designed to automate a sequence roughly similar to:

```text
Open/search project
        ↓
Open project
        ↓
Handle media dialog
        ↓
Trigger export
        ↓
Wait for render
        ↓
Return to project list
        ↓
Repeat
```

It exposes configurable delays for individual automation steps.

Because this feature is deprecated, use it only for testing or legacy workflows.

# 🐛 Troubleshooting

## Helper executable not found

If you see an error similar to:

```text
Executable not found
```

run:

```bash
npm run build-exe
```

before starting or packaging the application.

---

## `yt_dlp` not found while building

Install:

```bash
pip install yt-dlp
```

---

## `websockets` not found while building the trimmer

Install:

```bash
pip install websockets
```

---

## FFmpeg not found

Install FFmpeg and make sure it is available on your system.

The YouTube Trimmer also contains logic to obtain a portable FFmpeg build when it cannot find one on Windows.

---

## Marker key does nothing

Make sure the embedded YouTube player has focus.

Click the video and then press:

```text
,
```

The old README mentioned other keys in different places, but the current collector implementation uses **comma**.

---

## Wrong timestamp interpretation

Remember:

```text
1.20
```

means:

```text
1 minute 20 seconds
```

not `1.20` decimal seconds.

---

## CapCut project doesn't appear

The CapCut Shuffle scanner looks for project directories containing:

```text
draft_content.json
```

---

## YouTube download fails

YouTube frequently changes its delivery behavior.

Possible causes include:

* Rate limiting
* Authentication requirements
* Age restrictions
* Video unavailable/private
* Outdated `yt-dlp`
* Missing FFmpeg
* YouTube JavaScript challenge changes

Updating `yt-dlp` may help:

```bash
pip install -U yt-dlp
```
